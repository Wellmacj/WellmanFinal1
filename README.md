# WellmanFinal1 - ASP.NET MVC Project

## Overview
This is a video game themed ASP.NET MVC web application created as a final project. The website showcases my favorite video games including Deadlock, League of Legends, Minecraft, and Terraria.

## Features
- Home page introducing the site
- About Me page with personal information
- About Games page describing the hobby
- Games page connected to a SQL Server database
- Game Details pages with images and descriptions
- Navigation menu across all pages
- Entity Framework Core with LocalDB database
- Custom styling using CSS

## Technologies Used
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server LocalDB
- HTML / CSS / Bootstrap
- Git / GitHub

## Notes
Each game is stored in a database and displayed dynamically. The Details page shows more information about each game including an image and description.
